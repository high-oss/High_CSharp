# Changelog

All notable changes to this package are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] — 2026-09-29

First release. Pre-1.0: the surface may still change.

### Added

- `HighClient` covering 24 of the 27 HIGH Open API operations across five
  resources: `Auth`, `Orders`, `Portfolio`, `Scrips` and `Market`.
- `Instruments.Stream` (an `IAsyncEnumerable<Instrument>`, streamed without
  buffering the whole file) and `Instruments.List` (a materialised
  `IReadOnlyList<Instrument>`), for one of five categories (`All`, `Equity`,
  `Derivatives`, `Commodity`, `Etfs`) of the instrument list — a 17-column CSV
  of every scrip HIGH knows. Needs no credentials. Blank fields come back as
  `null`; `StrikePrice` is a `decimal?`; `PriceTick` is never rescaled.
- Hand-written models (`src/High.OpenApi/Models`) checked field-by-field
  against the canonical OpenAPI contract, pinned by commit in
  `spec.lock.json`, with a vendored `spec/openapi.json` and a conformance
  test suite that diffs `Environments`, `ErrorCodes` and `ExpiryType` against
  it on every run.
- Every spec enum is a real C# `enum` with a shared `SpecEnumConverter<T>`
  reading the exact wire string from `[EnumMember]` — never widened to
  `string` in a public signature.
- Configuration by `Environment` (`Production` / `Sandbox`) or explicit
  `BaseUrl`, with an independently settable `VersionPath`, and environment
  variable fallbacks (`HIGH_ENVIRONMENT`, `HIGH_BASE_URL`, `HIGH_WS_BASE_URL`,
  `HIGH_API_KEY`, `HIGH_ACCESS_TOKEN`, `HIGH_LOG_LEVEL`). An unknown
  environment or a bad numeric option fails at construction.
- One `HighApiError` for every failure, including timeouts and transport
  failures, carrying `Status`, `Code`, `RequestId`, `Messages` and `Body`.
- Retries for `GET` and `HEAD` only, on 429 and 5xx, honouring `Retry-After` in
  both its forms, capped by `MaxRetryDelayMs`. Writes are never retried.
- Configurable logging (`Silent` to `Debug`) with ISO-8601 timestamps, request
  and response bodies at `Debug`, and credential redaction throughout.
- Cancellation through a `CancellationToken` on every method, honoured during
  a retry delay as well as during a request; one timeout spans headers and body.
- Credentials excluded from `ToString()` and from `System.Text.Json`
  serialization of the client, its options and its resolved config.
- Built on `HttpClient`, constructor-injectable for `IHttpClientFactory`; no
  runtime NuGet dependencies.

### Notes

- The redirect consent flow and token introspection are not wrapped. Auth is
  the TOTP endpoint only.
- No datafeed socket client. `WsBaseUrl` is resolved but unused.
- Models are hand-written rather than generated by NSwag/OpenAPI Generator —
  see the plan for the reasoning. The vendored spec and conformance tests are
  the drift guard a generator would otherwise provide.
